# StudentManagement

Víceprojektová .NET aplikace pro správu studentů, známek a výuky.

## 🛠 Projekty

- `StudentManagement.Api` – REST API (.NET 8)
- `StudentManagement.Web` – Webová aplikace (Razor)
- `StudentManagement.Shared` – DTOs a sdílené typy

---

## 🚀 Rychlý start

### 1. Nainstaluj .NET 8 SDK  
[https://dotnet.microsoft.com/en-us/download/dotnet/8.0](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)

### 2. Nainstaluj `dotnet-script`  
```bash
dotnet tool install -g dotnet-script
```
Spust
```
dotnet script setup.csx
```
